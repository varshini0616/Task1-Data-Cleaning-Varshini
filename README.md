# Task 1: Data Cleaning Using Python

## Overview
This project demonstrates data cleaning techniques using Python and Pandas.

## Features
- Removes duplicate records
- Handles missing values
- Standardizes text data
- Renames columns for consistency
- Exports cleaned dataset

## Technologies Used
- Python 3
- Pandas

## Files
- data_cleaning.py – Main Python script
- data cleaning.py.pdf – Source code PDF
- readme.pdf – Project documentation

## Process
1. Load dataset
2. Check missing values
3. Remove duplicates
4. Fill missing values
5. Standardize text columns
6. Rename columns
7. Save cleaned dataset

## Output
The cleaned dataset is saved as:

cleaned_data.csv
